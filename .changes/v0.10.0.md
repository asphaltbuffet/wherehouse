## [0.10.0] - 2026-10-29

### Added

- Web UI: entity detail lists the entity's contents, each linking to its own detail
- Web UI: the home page lists the root entities with an Add root action, and breadcrumbs start at Inventory
- Web UI: on narrow screens the tree becomes a drawer opened from the header, and the detail panel uses the full width; clicking a tree chevron or + no longer also opens that entity
- use command and web Use action: temporarily move an entity while keeping its home; return sends displaced entities home; list --displaced and --home-under show what is out of place [#356]

### Changed

- `config set output.quiet` now takes a quiet level (0-2) instead of true/false; the Nix module's output.quiet accepts 0-2 (booleans still work), and existing config files with quiet = true/false still load [#279]
- Web UI: the "acting as" identity is shown in the footer on every page
- Web UI: Add root and Borrow moved from the header into the page actions; an entity page offers "Borrow into here"
- Web UI: larger touch targets on touch screens, full-screen add/borrow forms on phones, and no zoom when focusing search on iOS
- Web UI: entity history shows as stacked cards on phones

### Fixed

- Reject negative logging.max_size_mb / logging.max_backups and out-of-range output.quiet (must be 0-2) when loading config [#279]
- Web UI: Add child works on entities whose tree branch was never expanded, and the new entity appears in the detail panel
- Web UI: very long unbroken names and paths wrap instead of scrolling panels sideways
- Web UI: the tree highlights whichever entity the detail panel shows, and the add/borrow dialog no longer flashes the previous form
- Web UI: renaming an entity also renames its tree item and add button for screen readers [#348]
