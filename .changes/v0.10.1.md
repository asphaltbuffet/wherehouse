## [0.10.1] - 2026-10-30

### Added

- Web UI Reports page: missing, loaned, borrowed, displaced, by-parent, and all-entity reports with filters, CSV/JSON download, and a print view [355]

### Changed

- Locked entities are marked with an anchor instead of a padlock in `list` and the web UI, since locking only fixes location; the web tree also announces "locked" to screen readers

### Fixed

- Rebuilding an imported database (`doctor --rebuild`) keeps moved entities' descendants at their new paths, and rebuilding after a rename no longer duplicates path-change events [357]
- Renaming an entity in a way that keeps its canonical name (e.g. `Garage` → `garage`) updates its descendants' displayed paths [357]
- Web: the tree expands to and highlights the entity shown in the detail panel when you navigate there from the children list, breadcrumbs, search, or a direct URL; deep branches no longer overflow the tree on touch devices [363]
- Web pages that htmx can load as a fragment now send `Vary: Hx-Request, Hx-History-Restore-Request`, so a browser cache never serves a fragment for a full page load or the reverse [296]
- Web actions that aren't available now show why (the disabled button's reason) or a neutral "That action isn't available" instead of claiming the entity changed elsewhere; a whitespace loan recipient on a stale panel no longer reopens the loan form (#334); and stale form opens and removes refresh the tree status badge (#335) [336]

[0.10.1]: https://github.com/asphaltbuffet/wherehouse/compare/v0.10.0...v0.10.1
