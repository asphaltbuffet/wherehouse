## [0.10.2] - 2026-10-31

### Added

- Web UI: add and remove tags from the detail panel, with suggestions from tags already in use [324]
- Web UI: Esc closes the inline rename, loan, move, use, remove, and tag forms [324]
- Web UI: Mark missing, Mark found and Return open an inline form with an optional note, recorded on the event [291]

### Changed

- Web tree: clicking an item's name (or pressing Enter/Space) selects it without expanding or collapsing it; the chevron and the arrow keys expand and collapse without changing the selection [#364]
- Web tree: the expand/collapse chevron has a larger click area on desktop (at least 24px), so it is easier to hit [#364]

### Fixed

- `tag --add` rejects a tag that is only spaces, dashes, or underscores instead of recording an empty tag; an empty tag recorded by an earlier version can be removed with `tag --remove "--"` or its × in the web UI [324]
- Adding a tag an entity already has, or removing one it lacks, no longer adds an entry to its history [324]
- Entity paths in the web Reports table are readable in dark mode [372]
- Web: items added, borrowed, moved, or renamed now appear in alphabetical order in the inventory tree instead of at the end of their list [#295]
- `doctor --rebuild` no longer drops an event that another writer (such as `serve`) commits while the rebuild is loading the event log [#302]
