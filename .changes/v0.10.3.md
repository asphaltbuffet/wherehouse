## [0.10.3] - 2026-11-02

### Changed

- CLI rejection messages for status, move, remove and attribute changes now follow one wording; the web detail view disables Remove and Mark discrete on an entity that is home to displaced entities.

### Fixed

- Web Move/Use: a moved item keeps its expanded branch in the tree, the destination picker shows a message instead of stale options when the item is removed meanwhile, and a concurrent move no longer resets the wrong parent's chevron [#315]
- Doctor no longer reports soft-removed entities as phantom projection rows; it now flags a removed entity whose row is missing or whose status is not removed [#385]
- Web move/use picker no longer offers destinations that would put a displaced item's home inside it [#386]
- Web location picker shows each candidate's ID so same-named locations can be told apart in Borrow, Move and Use [294]
- doctor no longer reports a stale projection for descendants of a moved entity; each descendant now records its own path-changed event. [358]
- Web tree: keyboard focus is no longer lost when the focused row is removed, returned, or moved; a moved row keeps focus when it stays visible, otherwise focus goes to the next row, the previous row, or the parent [#304]
