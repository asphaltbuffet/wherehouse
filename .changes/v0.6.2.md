## [0.6.2] - 2026-10-24

### Added

- 'add' command accepts multiple arguments
- Entites may now be 'locked' and/or 'discrete'; flags added to appropriate commands
- Entities can be marked as 'missing' with 'lost' subcommand [#215]
- 'missing' entities can be marked 'ok' with the 'found' subcommand [#215]
- 'loaned' entities may be marked 'ok' with 'return' subcommand [#215]
- Allow creation of an entity with 'borrow' subcommand [#215]
- 'borrowed' items can be removed from tracking with 'return' subcommand [#215]
- TUI available by running application without a subcommand [#149]
- Each database instance can be named via 'db name' command
- 'info' command shows inventory information and sums entities by status
- (TUI) detail pane can be toggled
- multi-arch container image published to ghcr.io/asphaltbuffet/wherehouse

### Changed

- Icons in list output are based on 'locked' instead of type
- Status-transition commands (lost, found, loan, return) now reject illegal source statuses instead of performing no-op changes; loan --to is required. [#215]
- (TUI) history is shown in right pane as a toggle
- (TUI) Navigation uses nested entities with tree

### Removed

- Entities no longer have types; '--type' was removed from associated commands
- Entity status may no longer be set via 'status' command - changed to read-only by removing '--set' flag. [#215]

### Fixed

- Removed extra vertical spaces between entites in file list
- `--create-parents` actually creates missing ancestors
- (TUI) history shows each entity event
- (TUI) scry shows list of matched entities
- (TUI) User can select entities in scry results list
- Storage errors (DB unavailable, context cancelled) no longer surface as "entity not found"; they are now propagated with their original cause
- WHEREHOUSE_* environment variables are now applied when no config file exists
