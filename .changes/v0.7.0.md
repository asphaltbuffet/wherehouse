## [0.7.0] - 2026-10-25

### Added

- Web UI can record the user asserted by a trusted reverse proxy (e.g. Tailscale-User-Login) as the event actor via `serve --actor-header`, `web.actor_header` or `WHEREHOUSE_WEB_ACTOR_HEADER`; the page header shows "acting as …". [#267]
- Stderr log sink: set logging.file_path (or WHEREHOUSE_LOGGING_FILE_PATH) to "-". Rotation with the stderr sink is rejected, and config check now validates the merged files + environment configuration. The container image logs to stderr this way. [#257]

### Changed

- Update go to 1.26.10 and updated dependencies. [#225]

### Removed

- Free-text "User" field on the web add-item form; web visitors can no longer choose their own actor. [#145]
- WHEREHOUSE_LOG_PATH environment variable; use WHEREHOUSE_LOGGING_FILE_PATH. A warning is printed while it is still set. [#257]
- WHEREHOUSE_DB_PATH environment variable; use WHEREHOUSE_DATABASE_PATH. It never took effect; a warning is printed while it is still set. [#259]

### Fixed

- Web UI "+ Add root" button now opens the add dialog. [#268]
- An invalid configuration file or WHEREHOUSE_* environment value was silently replaced by defaults (including the database path); commands now fail with the validation error. config subcommands still run, with a warning. [#257]
