## [0.8.0] - 2026-10-26

### Added

- Web UI: Return action for borrowed and loaned entities (borrowed returns ask for confirmation)
- Web UI: Borrow button in the header creates a borrowed entity, with a searchable location picker defaulting to the entity being viewed
- Web UI: Loan action for ok and missing entities, with a required "Loaned to" and an optional note [#289]
- attr command and web detail-panel Lock/Unlock and Mark/Clear discrete buttons: change an entity's locked/discrete attributes after creation [#310]
- Web UI: Move action with a searchable destination picker, a move-to-root choice, and an optional note; disabled for locked, missing, or loaned entities
- web UI can remove an entity from its detail panel, with an optional note

### Changed

- borrow rejects a blank lender and names containing ':' or leading/trailing whitespace
- return refuses a borrowed entity that still contains other entities; return or move them first
- move rejects missing and loaned entities (find or return them first) and moves to the parent an entity is already in
- remove now refuses an entity that still contains other entities; remove or move them first [#287]

### Fixed

- Web UI no longer logs a Content-Security-Policy error on every page load [#286]
- web: a Return click that races another Return now shows the returned state instead of 'return failed' [#292]
- Concurrent status changes no longer fail with 'database is locked' or record duplicate events [#299]
- return, loan, lost and found reject a command that names the same entity twice instead of recording two events [#299]
- Web: returning a parent's last borrowed child now clears the parent's expand chevron in the tree. [#293]
- loan: a blank or whitespace-only --to is rejected, and the recipient is stored without surrounding spaces [#289]
- Web add-item form: replace the non-functional Type select with Locked and Discrete checkboxes [#284]
- move no longer accepts the entity itself or one of its descendants as the destination, which corrupted the hierarchy
- Concurrent move, rename, and tag operations (e.g. web UI and CLI at once) can no longer move an entity into a just-removed parent, create a parent cycle, or change a just-removed entity; a tag command now applies all of its changes or none [#301]
