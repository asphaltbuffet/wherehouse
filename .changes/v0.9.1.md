## [0.9.1] - 2026-10-28

### Changed

- Web UI redesign: workshop look with label-tape item names and shape-coded status marks; item detail now shows tags.

### Fixed

- web UI: browser Back no longer shows outdated names, statuses, or lock icons after a change [#314]
- web UI: a removed entity's page shows its last location and history (read-only) instead of 'entity not found', so browser Back to it works [#328]
- web UI: the inventory tree keeps responding to clicks and keys after browser Back [#327]
- web UI: adding or borrowing an item puts it under the location you picked, even when sibling locations share a name; a removed or discrete location shows an error instead of failing [#288, #144]
- Web UI: actions on an out-of-date item panel now show the item's current state with an inline message instead of silently doing nothing, and Mark missing can no longer mark an item found. [#306]
