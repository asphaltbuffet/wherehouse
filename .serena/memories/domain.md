# Domain Terms

See CONTEXT.md for full glossary. Key terms for agents:

- **Entity** — unified type for everything (place, container, leaf). Never "item"/"location".
- **EntityPathChangedEvent** — derived event auto-generated by `propagatePathChangesTx` when an `EntityReparentedEvent` is handled. Never replay it through `applyEventTx` (see ADR-0009).
- **Projection** — `entities_current` table. Rebuildable. Not authoritative.
- **Scry** — Levenshtein search command. Not "fuzzy match".
- **Remove** — soft-delete via `EntityRemovedEvent`. Not "delete".
- **DoctorIssue** — structural problem found by doctor validation. Fields: Kind, EventID (*int64), Description.
- **DoctorKind** — iota: config / event_log / projection.
