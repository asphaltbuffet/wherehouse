## [0.10.2] - 2026-10-31

### Added

- Web UI: add and remove tags from the detail panel, with suggestions from tags already in use [324]
- Web UI: Esc closes the inline rename, loan, move, use, remove, and tag forms [324]
- Web UI: Mark missing, Mark found and Return open an inline form with an optional note, recorded on the event [291]

### Changed

- Web tree: clicking an item's name (or pressing Enter/Space) selects it without expanding or collapsing it; the chevron and the arrow keys expand and collapse without changing the selection [#364]
- Web tree: the expand/collapse chevron has a larger click area on desktop (at least 24px), so it is easier to hit [#364]

### Fixed

- `tag --add` rejects a tag that is only spaces, dashes, or underscores instead of recording an empty tag; an empty tag recorded by an earlier version can be removed with `tag --remove "--"` or its × in the web UI [324]
- Adding a tag an entity already has, or removing one it lacks, no longer adds an entry to its history [324]
- Entity paths in the web Reports table are readable in dark mode [372]
- Web: items added, borrowed, moved, or renamed now appear in alphabetical order in the inventory tree instead of at the end of their list [#295]
- `doctor --rebuild` no longer drops an event that another writer (such as `serve`) commits while the rebuild is loading the event log [#302]

[0.10.2]: https://github.com/asphaltbuffet/wherehouse/compare/v0.10.1...v0.10.2


## [0.10.1] - 2026-10-30

### Added

- Web UI Reports page: missing, loaned, borrowed, displaced, by-parent, and all-entity reports with filters, CSV/JSON download, and a print view [355]

### Changed

- Locked entities are marked with an anchor instead of a padlock in `list` and the web UI, since locking only fixes location; the web tree also announces "locked" to screen readers

### Fixed

- Rebuilding an imported database (`doctor --rebuild`) keeps moved entities' descendants at their new paths, and rebuilding after a rename no longer duplicates path-change events [357]
- Renaming an entity in a way that keeps its canonical name (e.g. `Garage` → `garage`) updates its descendants' displayed paths [357]
- Web: the tree expands to and highlights the entity shown in the detail panel when you navigate there from the children list, breadcrumbs, search, or a direct URL; deep branches no longer overflow the tree on touch devices [363]
- Web pages that htmx can load as a fragment now send `Vary: Hx-Request, Hx-History-Restore-Request`, so a browser cache never serves a fragment for a full page load or the reverse [296]
- Web actions that aren't available now show why (the disabled button's reason) or a neutral "That action isn't available" instead of claiming the entity changed elsewhere; a whitespace loan recipient on a stale panel no longer reopens the loan form (#334); and stale form opens and removes refresh the tree status badge (#335) [336]

## [0.10.0] - 2026-10-29

### Added

- Web UI: entity detail lists the entity's contents, each linking to its own detail
- Web UI: the home page lists the root entities with an Add root action, and breadcrumbs start at Inventory
- Web UI: on narrow screens the tree becomes a drawer opened from the header, and the detail panel uses the full width; clicking a tree chevron or + no longer also opens that entity
- use command and web Use action: temporarily move an entity while keeping its home; return sends displaced entities home; list --displaced and --home-under show what is out of place [#356]

### Changed

- `config set output.quiet` now takes a quiet level (0-2) instead of true/false; the Nix module's output.quiet accepts 0-2 (booleans still work), and existing config files with quiet = true/false still load [#279]
- Web UI: the "acting as" identity is shown in the footer on every page
- Web UI: Add root and Borrow moved from the header into the page actions; an entity page offers "Borrow into here"
- Web UI: larger touch targets on touch screens, full-screen add/borrow forms on phones, and no zoom when focusing search on iOS
- Web UI: entity history shows as stacked cards on phones

### Fixed

- Reject negative logging.max_size_mb / logging.max_backups and out-of-range output.quiet (must be 0-2) when loading config [#279]
- Web UI: Add child works on entities whose tree branch was never expanded, and the new entity appears in the detail panel
- Web UI: very long unbroken names and paths wrap instead of scrolling panels sideways
- Web UI: the tree highlights whichever entity the detail panel shows, and the add/borrow dialog no longer flashes the previous form
- Web UI: renaming an entity also renames its tree item and add button for screen readers [#348]

## [0.8.0] - 2026-10-26

### Added

- Web UI: Return action for borrowed and loaned entities (borrowed returns ask for confirmation)
- Web UI: Borrow button in the header creates a borrowed entity, with a searchable location picker defaulting to the entity being viewed
- Web UI: Loan action for ok and missing entities, with a required "Loaned to" and an optional note [#289]
- attr command and web detail-panel Lock/Unlock and Mark/Clear discrete buttons: change an entity's locked/discrete attributes after creation [#310]
- Web UI: Move action with a searchable destination picker, a move-to-root choice, and an optional note; disabled for locked, missing, or loaned entities
- web UI can remove an entity from its detail panel, with an optional note

### Changed

- borrow rejects a blank lender and names containing ':' or leading/trailing whitespace
- return refuses a borrowed entity that still contains other entities; return or move them first
- move rejects missing and loaned entities (find or return them first) and moves to the parent an entity is already in
- remove now refuses an entity that still contains other entities; remove or move them first [#287]

### Fixed

- Web UI no longer logs a Content-Security-Policy error on every page load [#286]
- web: a Return click that races another Return now shows the returned state instead of 'return failed' [#292]
- Concurrent status changes no longer fail with 'database is locked' or record duplicate events [#299]
- return, loan, lost and found reject a command that names the same entity twice instead of recording two events [#299]
- Web: returning a parent's last borrowed child now clears the parent's expand chevron in the tree. [#293]
- loan: a blank or whitespace-only --to is rejected, and the recipient is stored without surrounding spaces [#289]
- Web add-item form: replace the non-functional Type select with Locked and Discrete checkboxes [#284]
- move no longer accepts the entity itself or one of its descendants as the destination, which corrupted the hierarchy
- Concurrent move, rename, and tag operations (e.g. web UI and CLI at once) can no longer move an entity into a just-removed parent, create a parent cycle, or change a just-removed entity; a tag command now applies all of its changes or none [#301]

[0.8.0]: https://github.com/asphaltbuffet/wherehouse/compare/v0.7.0...v0.8.0


## [0.7.0] - 2026-10-25

### Added

- Web UI can record the user asserted by a trusted reverse proxy (e.g. Tailscale-User-Login) as the event actor via `serve --actor-header`, `web.actor_header` or `WHEREHOUSE_WEB_ACTOR_HEADER`; the page header shows "acting as …". [#267]
- Stderr log sink: set logging.file_path (or WHEREHOUSE_LOGGING_FILE_PATH) to "-". Rotation with the stderr sink is rejected, and config check now validates the merged files + environment configuration. The container image logs to stderr this way. [#257]

### Changed

- Update go to 1.26.10 and updated dependencies. [#225]

### Removed

- Free-text "User" field on the web add-item form; web visitors can no longer choose their own actor. [#145]
- WHEREHOUSE_LOG_PATH environment variable; use WHEREHOUSE_LOGGING_FILE_PATH. A warning is printed while it is still set. [#257]
- WHEREHOUSE_DB_PATH environment variable; use WHEREHOUSE_DATABASE_PATH. It never took effect; a warning is printed while it is still set. [#259]

### Fixed

- Web UI "+ Add root" button now opens the add dialog. [#268]
- An invalid configuration file or WHEREHOUSE_* environment value was silently replaced by defaults (including the database path); commands now fail with the validation error. config subcommands still run, with a warning. [#257]

[0.7.0]: https://github.com/asphaltbuffet/wherehouse/compare/v0.6.2...v0.7.0


## [0.6.2] - 2026-10-24

### Added

- 'add' command accepts multiple arguments
- Entites may now be 'locked' and/or 'discrete'; flags added to appropriate commands
- Entities can be marked as 'missing' with 'lost' subcommand [#215]
- 'missing' entities can be marked 'ok' with the 'found' subcommand [#215]
- 'loaned' entities may be marked 'ok' with 'return' subcommand [#215]
- Allow creation of an entity with 'borrow' subcommand [#215]
- 'borrowed' items can be removed from tracking with 'return' subcommand [#215]
- TUI available by running application without a subcommand [#149]
- Each database instance can be named via 'db name' command
- 'info' command shows inventory information and sums entities by status
- (TUI) detail pane can be toggled
- multi-arch container image published to ghcr.io/asphaltbuffet/wherehouse

### Changed

- Icons in list output are based on 'locked' instead of type
- Status-transition commands (lost, found, loan, return) now reject illegal source statuses instead of performing no-op changes; loan --to is required. [#215]
- (TUI) history is shown in right pane as a toggle
- (TUI) Navigation uses nested entities with tree

### Removed

- Entities no longer have types; '--type' was removed from associated commands
- Entity status may no longer be set via 'status' command - changed to read-only by removing '--set' flag. [#215]

### Fixed

- Removed extra vertical spaces between entites in file list
- `--create-parents` actually creates missing ancestors
- (TUI) history shows each entity event
- (TUI) scry shows list of matched entities
- (TUI) User can select entities in scry results list
- Storage errors (DB unavailable, context cancelled) no longer surface as "entity not found"; they are now propagated with their original cause
- WHEREHOUSE_* environment variables are now applied when no config file exists

[0.6.2]: https://github.com/asphaltbuffet/wherehouse/compare/v0.6.0...v0.6.2
